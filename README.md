## 📌 Про проєкт

**«ХімоМнемоніка PRO»** поєднує фундаментальні фізико-хімічні дані, інтерактивні 3D-моделі та мнемонічні техніки для швидкого, легкого та глибокого засвоєння хімії. Весь клієнтський інтерфейс розроблено як автономний SPA/PWA вебдодаток, орієнтований на розгортання через GitHub Pages.

---

## ✨ Ключові можливості

### 🧪 1. Повна Періодична система (1–118)
* **Стандартизовані назви:** Офіційна подвійна українська номенклатура IUPAC (*Гідроген (водень)*, *Карбон (вуглець)*, *Ферум (залізо)*, *Купрум (мідь)* тощо).
* **Режими візуалізації таблиці:**
  * За хімічними групами й родинами.
  * За орбітальними квантовими блоками ($s, p, d, f$).
  * За шкалою електронегативності Полінга ($\chi$) у форматі теплової карти.
* **Живий пошук та фільтри:** Миттєвий пошук за атомним номером, символом або назвою.

---

### 🌐 2. Інтерактивна 3D-лабораторія
* **Квантова Модель Бора (360°):**
  * Динамічний розрахунок електронних оболонок ($K, L, M, N, O, P, Q$) за принципом Ауфбау (правило Клечковського).
  * Анімований рух електронів по орбіталях, пульсуюче ядро, вільне обертання мишкою або тач-жестами.
* **Просторові Кристалічні Ґратки:**
  * Повноцінна 3D-проєкція вузлів і зв'язків: **ОЦК** (Fe, W, Na), **ГЦК** (Au, Cu, Al), **ГПУ** (Mg, Ti), **Алмазна** (C, Si) та молекулярні структури.

---

### 📸 3. Динамічна галерея зразків
* **Підтримка багатьох зображень:** Мініслайдер з перемиканням знімків (`‹` / `›`) та повноекранний **Lightbox**.
* **Автоматичне додавання медіа:** Додаток зчитує `gallery.json`. Додавання нових фотографій у папки `images/{Z}/` не потребує змін у коді `index.html`.
* **Автономні SVG-заглушки:** Захист від відсутності мережі або для надважких ядерних синтетиків.

---

### 🌈 4. Оптична спектроскопія
* Перемикання між **емісійним** (лінійчастим випромінюванням) та **абсорбційним** спектром (темні лінії поглинання Фраунгофера на райдужному тлі) у діапазоні $380–750\text{ нм}$.

---

### 🧩 5. Мнемоніка, гейміфікація та інструменти
* **Мнемонічні рими та синтез мовлення:** Авторські асоціативні вірші для кожного елемента з озвученням українською через Web Speech API.
* **Порівняння Side-by-Side:** Одночасний аналіз параметрів двох обраних елементів.
* **Конструктор реакцій (Sandbox):** Моделювання бінарних взаємодій ($H_2O$, $NaCl$, $CO_2$, $Fe_2O_3$).
* **Квіз-тренажер:** Тестування знань із фіксацією рекорду в `localStorage`.
* **Print View (PDF):** Готова адаптивна розмітка для друку навчальних карток.
* **PWA & Offline:** Підтримка роботи без доступу до інтернету завдяки Service Worker.

## 📁 Структура репозиторію

```text
├── index.html                     # Головний односторінковий додаток (SPA)
├── gallery.json                   # Маніфест шляхів до зображень елементів
├── manifest.json                  # PWA-маніфест для встановлення як додаток
├── sw.js                          # Service Worker для офлайн-кешування
├── fetch_wiki_to_existing.py      # Скрипт парсингу Вікіпедії в папки images/{Z}/
├── update_gallery.py              # Швидке оновлення gallery.json після додавання фото
├── .github/
│   └── workflows/
│       └── update_gallery.yml     # GitHub Actions: авто-оновлення gallery.json при пуші
└── images/
    ├── 1/                         # Папка Гідрогену (main.jpg, wiki_1.jpg, ...)
    ├── 2/                         # Папка Гелію
    └── ...                        # Папки до 118
